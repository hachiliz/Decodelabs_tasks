# Decode-labs-internship
## Project overview 
this project focuses on executing a rigorous **Exploratory data analysis (EDA)** and buildingan enterprise-grade dashboard using power BI**. Operating under an analytical data-integrity framework, the dashboard translates over1,200 raw transactional line items into immediate actionable insights. It evaluates financial distribution anomalies, identifies temporal sales patterns, and diagnose logistical bottlenecks to optimize operational work flow.
